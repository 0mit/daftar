A dinner where something was agreed

Ali came to dinner at Sam's on 12 September 2026, and they agreed the loan for her washing machine there. Nothing was written down. The dinner is an event; the loan's words say they were spoken, and where.

garden-sam · daftar v0.33.1 · the day held at 2026-10-27

What the notebook records

A happening between people is owned by none of them: it ends at the crown, logos, as an agreement may, and whoever hosted it answers for it. When it began is timing, at the resolution actually known — a minute, with its offset. Who took part is refs, each naming what they were:

beans/dinner-at-sams.md---
bean: dinner-at-sams
kind: event
title: "dinner-at-sams — dinner at Sam's, where the washing-machine loan was agreed"
status: active
summary: "Ali came to dinner at Sam's; they agreed the loan for her washing machine."
nature: metaphysical
identity:
  status: confirmed
  anchors:
    - { key: event_id, value: "event:dinner-at-sams-2026-09-12", class: logical, establishing: true }
provenance: { src: asserted-by-human, by: "sam", as_of: 2026-09-17 }
owned_by: { legal: { crown: logos } }
responsibility: { legal: { holder: { bean: sam } } }
timing:
  start: { system: gregorian-civil, at: "2026-09-12 19:30+03:00", unit: minute }
refs:
  host:  { bean: sam, rel: host }
  guest: { bean: ali, rel: present }
---

What it shows

  • An agreement's words are recorded as they stand: written in a document, spoken at an event, or not yet put into words.
  • No calendar is privileged. A moment is written in the calendar it was known in, and two calendars are compared through the day they both fall on. No privileged sibling.
  • A tool refuses rather than approximates. A date silently wrong by a day is worse than no date.
